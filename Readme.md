
### Что потребуется:
1. **Docker Desktop** .
2. Минимум **8 ГБ оперативной памяти** (рекомендуется 16 ГБ) для комфортной работы нейросети.
3. Стабильное интернет-соединение (при первом запуске скачается модель ИИ весом ~5 ГБ).

---
### Краткое описание проекта
Проект сделан для сбора новостей с информационных ресурсов в формате Rss. В нём представлена лента новостей, в режиме
реального времени загружаются новости с источников и сохраняются в БД. Так же представлена LLM-модель(локальная), готовое решение от Deepseek`a,
которая работает в качестве аналитика, модель читает все новости и анализирует их, переводит английские заголовки на русский, отбрасывает «мусор» и формирует связный список новостей .
Так же реализован чат с нейросетью.
### ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ (Конфликт портов)
Если на вашем компьютере **уже установлена программа Ollama** (для локальных нейросетей), её необходимо **полностью закрыть** (нажать правой кнопкой мыши на иконку в трее -> Quit Ollama).
Иначе Docker не сможет запустить свою встроенную Ollama и выдаст ошибку `bind: Only one usage of each socket address`.

### Пошаговый запуск:

**Шаг 1. Подготовка**
Убедитесь, что **Docker Desktop** запущен и работает (иконка кита в трее не должна анимироваться).

**Шаг 2. Скачивание проекта**
Скачайте архив с проектом и распакуйте его в любую папку, либо склонируйте через Git:



Шаг 3. Запуск контейнеров
Откройте терминал (Командную строку или PowerShell) в папке с проектом (там, где лежит файл docker-compose.yml) и выполните команду:
```bash

docker compose up -d --build

```
Docker начнет сборку проекта и скачивание необходимых образов.

Шаг 4. Ожидание загрузки нейросети (САМЫЙ ВАЖНЫЙ ШАГ)
При первом запуске Docker начнет скачивать языковую модель qwen2.5:7b (около 5 ГБ). Это может занять от 5 до 30 минут в зависимости от скорости интернета.
Чтобы посмотреть прогресс скачивания, выполните в терминале:

```bash
docker compose logs -f ollama-model-loader
```
Дождитесь появления сообщения Model pulled successfully!. После этого можно нажать Ctrl + C, чтобы выйти из просмотра логов.

Шаг 5. Открытие приложения
Откройте ваш браузер (Chrome, Яндекс.Браузер и т.д.) и перейдите по адресу:
 http://localhost:8080
